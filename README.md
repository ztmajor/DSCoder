# DSH-Delve
DSH-Delve-Desktop 是 DeepSeek Harness 的桌面客户端，基于 Tauri + Rust 构建，兼具极致的性能与轻盈的资源占用。  它不仅仅是一个简单的封装，更为你的 AI 工作流提供了一个集成化的开发环境。核心功能包括：  文件管理器：直观的项目导航，轻松浏览和管理工作目录。  代码阅读器：针对大规模代码库优化，语法高亮，阅读流畅。  Code Diff 工具：清晰比对代码变更，精准追踪每一次修改。  无论你是正在微调模型的数据科学家，还是深入探索复杂仓库的开发者，DSH-Delve-Desktop 都能将 Harness 的强大能力带到你的指尖——原生支持 Windows 和 Linux，开箱即用。
